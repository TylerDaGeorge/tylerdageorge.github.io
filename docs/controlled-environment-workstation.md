# Controlled Environment Workstation (CEW)

## Product Overview

The Eden Industrial Systems Controlled Environment Workstation (CEW) combines the Eden Stainless Clean Environment Table with the Eden Controlled Environment Chamber (CEC) into a complete point-of-use clean-environment workstation.

The workstation is intended for cleanrooms, laboratories, controlled manufacturing areas, and other contamination-sensitive environments where an operator benefits from having both:

1. An open stainless steel work surface for normal process activities.
2. A localized HEPA-filtered controlled zone for sensitive components, assemblies, samples, tools, or work-in-process.

The CEW allows a customer to place a higher-cleanliness controlled zone directly beside the active work area without requiring the entire surrounding room to operate at the same cleanliness level.

A representative application is an operator working in an ISO Class 7 or ISO Class 8 cleanroom who periodically needs to protect sensitive work in a localized environment designed and validated for a higher cleanliness classification, potentially including ISO Class 5.

> **Important:** The workstation's controlled-environment performance is determined by the CEC configuration and operating conditions. No ISO cleanliness classification should be advertised until the applicable CEC configuration has been tested and validated using the relevant ISO 14644 requirements.

## Product Concept

The Controlled Environment Workstation is based on a simple workflow:

```text
OPEN WORK AREA                 CONTROLLED ZONE
+----------------------+       +----------------------+
|                      |       |                      |
| Normal Process Work  | <---> | Sensitive Material  |
| Assembly             |       | Work-in-Process      |
| Inspection           |       | Temporary Storage    |
| Preparation          |       | Protected Staging    |
|                      |       |                      |
+----------------------+       +----------------------+
        |                              |
        +------------------------------+
                 One Workstation
```

The operator can perform normal work on the open stainless steel portion of the table while keeping a controlled chamber immediately within reach.

When a sensitive item requires protection, the operator places it inside the CEC and closes the access doors. HEPA-filtered airflow continuously purges the chamber and maintains the localized controlled environment according to the validated performance of the installed CEC.

## Operator Workflow

A representative workflow is:

1. The operator performs normal assembly, inspection, preparation, or other work on the open stainless steel work surface.
2. A sensitive component reaches a stage where additional environmental protection is required.
3. The operator opens the CEC doors.
4. The component is placed on the internal rack or shelf.
5. The doors are closed.
6. The CEC recovers to its specified controlled condition.
7. The component remains protected while the operator performs other tasks, pauses the process, takes a break, or waits for the next process step.
8. The operator retrieves the component when work resumes.

The close physical relationship between the open work area and controlled zone is a primary feature of the workstation.

## Stainless Clean Environment Table

The standard CEW table is based on the Eden Stainless Clean Environment Table.

### Work Surface

- Type 304 stainless steel
- 16 gauge
- 72 in. standard width
- 30 in. standard depth
- 30 in. or 36 in. finished work-surface height

### Surface Configuration

The CEW may use:

- Solid stainless steel work surface
- Perforated stainless steel work surface

The preferred standard CEW surface configuration should be determined after CEC airflow testing.

If perforations are used beneath or around the CEC, engineering must determine whether they improve or interfere with the intended airflow pattern.

### Frame

- Type 304 stainless steel
- Welded to underside of work surface
- Designed to resist racking
- Provides mounting locations for bolt-on legs

### Legs

- Type 304 stainless steel
- Bolt to welded frame
- Adjustable leveler at each leg

The table must be rated to support the CEC plus the intended work-surface loads with an appropriate safety factor.

## Airflow

The CEC airflow system remains the primary environmental-control system within the workstation.

The preliminary airflow path is:

```text
Surrounding Cleanroom Air
          |
          v
      CEC Intake
          |
          v
     Pre-Filter*
          |
          v
    Blower / Fan
          |
          v
      HEPA Filter
          |
          v
 Filtered Supply Air
          |
          v
   Controlled Zone
          |
          v
 Lower-Level Exhaust
          |
          v
 Surrounding Cleanroom
```

`*` Pre-filter requirement and location are to be determined during CEC engineering.

The table and workstation geometry must not interfere with:

- CEC air intake
- Exhaust airflow
- Door operation
- Filter service
- Blower cooling
- Required clearances

## Recovery Time

Because the CEC doors are opened during loading and unloading, the controlled zone will be disturbed during normal use.

Recovery time should therefore be considered a key workstation performance characteristic.

**Recovery Time:** The elapsed time after the CEC doors are closed until the controlled zone returns to its specified cleanliness condition.

A validated recovery-time specification could provide operators with a practical indication of when the chamber has returned to its qualified condition.

Potential future workstation features may include:

- Recovery timer
- Clean-zone ready indicator
- Door-status switch
- Airflow-status indicator

These features should only be incorporated if testing demonstrates that they provide meaningful operational value.

## CEC Retention

Although the standalone CEC uses feet and rests on the work surface, the integrated workstation should be evaluated for a positive retention method.

Potential approaches include:

- CEC resting freely on non-slip feet
- Locating pins
- Hidden brackets
- Bolted attachment
- Tool-less retention hardware

The retention system should prevent unintended movement without creating unnecessary contamination traps or making cleaning difficult.

If the CEC is mechanically attached to the table, removal for service should remain straightforward.

## Installation

A preliminary installation sequence is:

1. Unpack and inspect all components.
2. Assemble the Stainless Clean Environment Table.
3. Position the table in its intended location.
4. Adjust the table levelers until the work surface is level and stable.
5. Place the CEC in its specified location on the table.
6. Install any CEC retention hardware, if applicable.
7. Install the internal rack.
8. Connect electrical power.
9. Verify that CEC intake and exhaust openings are unobstructed.
10. Verify door operation.
11. Start the CEC blower.
12. Perform required airflow or environmental verification before process use.

Final installation instructions will be established after engineering validation.
