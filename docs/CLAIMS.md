# Claims Guardrails

Never invent customers, results, performance metrics, ROI, cycle-time or scrap reductions, certifications, safety validation, fabrication capabilities, controls capabilities, or production use. Do not present a design project as a field-proven installation or make unsupported turnkey claims.

Acceptable qualifiers include: “designed to,” “can be evaluated for,” “potential applications include,” “mechanical design scope,” “build-ready documentation,” “project-specific,” “quoted separately,” and “may require qualified integration partners.”
