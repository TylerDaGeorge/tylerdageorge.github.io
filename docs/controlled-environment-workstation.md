# Optional CSC and EIS Table Package

The HEPA-Filtered Clean Staging Chamber (CSC) may be supplied with an EIS stainless steel table when a customer needs both the chamber and a dedicated work surface. This is a purchasing/configuration option, not a separate named product.

Do not introduce a name or acronym for this combination. Do not imply that an EIS table is required: the CSC is designed for suitable existing workbenches, tables, laboratory benches, inspection stations, assembly stations, carts, and other suitable work surfaces.
