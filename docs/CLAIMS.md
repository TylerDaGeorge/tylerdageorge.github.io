# Eden Industrial Systems — Claims and Technical Guardrails

## 1. Purpose

This document defines what Eden Industrial Systems may and may not claim on the website at the current stage of product development.

It should be read alongside:

- `WEBSITE-PLAN.md`
- `PRODUCT.md`
- `DESIGN.md`
- `CONTENT.md`

When in doubt, technical accuracy takes priority over stronger marketing language.

Do not strengthen, extrapolate, or reinterpret claims beyond what is explicitly supported.

---

# 2. Core Rule

If a performance characteristic has not been:

- Engineered
- Selected
- Measured
- Tested
- Validated
- Documented

then it must not be presented as a confirmed product capability.

Unknown values should be:

- Omitted from customer-facing content
- Marked TBD in internal documentation
- Described cautiously when appropriate

Never invent a number to complete a table or design.

---

# 3. Approved General Positioning

The following claims are approved as general positioning:

- Eden develops localized process environments for critical processes.
- Eden develops HEPA-filtered workstations for manufacturing and handling applications.
- The Eden Clean Process Chamber is designed around localized HEPA-filtered airflow.
- The system is intended to create a controlled work zone around a process.
- The Clean Process Chamber uses a downward airflow concept.
- The system is intended to concentrate environmental control around the working area.
- Eden also offers or develops stainless cleanroom workstations.
- Eden products may be configured around customer applications.

These statements must still remain consistent with the latest `PRODUCT.md`.

# 5. Conditional Language

Use conditional language when a feature or capability is still conceptual or application-dependent.

Preferred phrasing:

- Designed to
- Intended to

# 6. HEPA Claims

Approved:

- HEPA filtration
- HEPA-filtered air
- HEPA-filtered supply air
- Designed around HEPA filtration

Not approved unless a specific filter has been selected and documented:

- 99.97% at 0.3 microns
- 99.995% efficiency
- H13
- H14
- ULPA
- Specific filter class
- Specific filter efficiency

Do not assume a standard HEPA efficiency value.

Use only the actual selected filter specification once it is documented.

---

# 7. Cleanroom Classification

Do not claim any ISO cleanliness classification unless supported by testing under defined conditions.

Not approved by default:

- ISO Class 5
- ISO Class 6
- ISO Class 7
- ISO Class 8
- Class 100
- Class 1,000
- Class 10,000
- Class 100,000

HEPA filtration alone does not establish a cleanroom classification.

---

# 8. Cleanroom Equivalence

Do not claim:

- Replaces a cleanroom
- Equivalent to a cleanroom
- Same performance as a cleanroom
- Cleanroom in a box
- Eliminates the need for a cleanroom
- No cleanroom required

Approved alternative:

> **Localized process-environment control may reduce the need to control a larger surrounding area for some applications.**

Even this should not be framed as universal.

# 10. Contamination Claims

Do not claim:

- Contamination-free
- Zero contamination
- Eliminates contamination

- Create a cleaner localized work zone

Use "reduce" only where context makes it clear this is a design objective, not a guaranteed measured outcome.

# 39. Numbers Rule

Every customer-facing technical number should have a source.

Examples:

- Dimensions
- Weight
- Efficiency
- Airflow
- Noise
- Electrical
- Pressure
- Temperature
- Lead time
- Price

If the source cannot be identified, do not publish the number.

---

# 40. Specification Table Rule

Do not populate empty specification tables with guessed values.

If only three specifications are known, publish three.

A short accurate specification table is better than a complete-looking fictional one.

---

# 41. Diagram Rule

Technical diagrams must not imply unsupported performance.

Do not add:

- Velocity numbers
- Particle counts
- ISO class labels
- Pressure values
- Efficiency values

unless documented.

Directional arrows are acceptable when they reflect the intended airflow architecture.

---

# 42. Marketing Rewrite Rule

Codex must not transform cautious technical language into stronger claims.

Example:

Approved:

> **The system is intended to distribute filtered air across the work zone.**

Not approved:

> **The system guarantees perfectly uniform airflow.**

Approved:

> **HEPA-filtered supply air**

Not approved:

> **Hospital-grade purified air**

Approved:

> **Localized HEPA-filtered work zone**

Not approved:

> **Portable ISO cleanroom**

---

# 43. Claims Review Rule

Before adding a new product claim, check:

1. Is it explicitly supported in `PRODUCT.md`?
2. Is it allowed by this document?
3. Does it require test data?
4. Does it imply certification?
5. Does it imply regulatory suitability?
6. Does it imply guaranteed performance?
7. Is there a real source for any number used?

If any answer creates uncertainty, use weaker language or omit the claim.

unless demonstrably true.

# 45. Current Approved Core Claims

At the current product-development stage, the safest core claims are:

> **Eden Industrial Systems develops equipment for localized process environments for critical manufacturing and handling processes.**

> **The Eden Clean Process Chamber is designed around downward HEPA-filtered airflow through a localized work zone.**

> **The system is intended to concentrate process-environment control around the process rather than automatically controlling an entire surrounding room.**

> **Eden also develops stainless workstations for clean manufacturing environments and integration with process airflow systems.**

These statements should remain the baseline until additional product testing supports stronger claims.

---

# 46. Final Rule

When choosing between:

**Stronger marketing copy**

and

**More technically accurate copy**

choose technical accuracy.

The website should earn credibility by being precise rather than sounding impressive.
