# Eden Industrial Systems — SEO Strategy

## 1. Purpose

This document defines the search engine optimization direction for the Eden Industrial Systems website.

It should be read alongside:

* `WEBSITE-PLAN.md`
* `PRODUCT.md`
* `DESIGN.md`
* `CONTENT.md`
* `CLAIMS.md`
* `TECHNICAL.md`

This document governs:

* Page titles
* Meta descriptions
* Search themes
* Heading structure
* Internal linking
* Canonical URLs
* Sitemap behavior
* Robots behavior
* Structured data
* Image SEO
* Content priorities

The objective is to help qualified buyers find Eden when searching for equipment for localized process environments, HEPA workstations, clean process chambers, and related manufacturing solutions.

SEO must never override technical accuracy.

Do not add unsupported claims simply because they may attract search traffic.

---

# 2. Primary SEO Goal

The website should attract users searching for:

* Localized process environments
* HEPA-filtered workstations
* HEPA-filtered chambers
* Clean process chambers
* Cleanroom workstations
* Stainless cleanroom workstations
* Controlled-environment workstations
* Clean workstations for manufacturing
* Localized clean zones
* Clean-air equipment for assembly
* Clean-air equipment for inspection
* Clean-air equipment for packaging

The site should prioritize commercial and technical search intent over broad informational traffic.

---

# 3. Search Intent Priority

Prioritize search intent in this order:

## 1. Product / Commercial Intent

Users looking for equipment to buy or quote.

Examples:

* HEPA workstation
* clean air workstation
* clean process chamber
* cleanroom workstation
* stainless cleanroom table
* localized clean air system
* clean bench alternative

## 2. Application Intent

Users looking for a solution to a process problem.

Examples:

* clean air for assembly
* clean environment for inspection
* clean workstation for packaging
* particulate control for electronics assembly
* localized clean zone for manufacturing

## 3. Technical Research Intent

Users trying to understand how the equipment works.

Examples:

* HEPA workstation airflow
* vertical airflow workstation
* clean bench vs cleanroom
* localized clean air vs cleanroom

Do not build a large informational content library until the core commercial pages are strong.

---

# 4. Primary Website Pages

SEO should be centered around the four approved public pages:

* Home
* Products
* Contact
* Request a Quote

Do not create additional pages solely for SEO without explicit approval.

# 5. Homepage SEO Objective

The homepage should target the broad company/category concept.

Primary theme:

**Localized Process Environments**

Secondary themes:

* HEPA-filtered workstations
* Clean-air systems for manufacturing
* Clean process chambers
* Clean manufacturing workstations

The homepage should establish what Eden is and what category of equipment it makes.

---

# 6. Homepage Title

Preferred:

**Eden Industrial Systems | Localized Process Environments**

Alternative if character length becomes an issue:

**Localized Process Environments | Eden Industrial Systems**

Do not stuff multiple keyword variants into the title.

Avoid:

**HEPA Cleanroom Clean Bench Laminar Flow Workstation Manufacturer | Eden**

---

# 7. Homepage Meta Description

Preferred:

**Eden Industrial Systems develops localized HEPA-filtered clean-air workstations for critical manufacturing, assembly, inspection, and packaging processes.**

Keep the final implementation concise enough to display well in search results.

---

# 8. Homepage H1

Use:

The H1 does not need to exactly match the primary keyword if the surrounding content clearly establishes the product category.

# 24. Heading Structure

Each page should have exactly one primary H1.

Use logical hierarchy:

```text
H1
  H2
    H3
```

Do not use headings solely for visual styling.

Example Products page:

```text
H1 Process Environments Built Around the Work
  H2 Eden Clean Process Chamber
    H3 HEPA Filtration
    H3 Air Distribution
    H3 Vertical Airflow
  H2 Configuration
  H2 Eden Cleanroom Workstations
```

---

# 25. Internal Linking

Use internal links naturally.

Important internal paths:

Homepage → Products

Homepage → Request a Quote

Products → Request a Quote

Products → Contact

Contact → Request a Quote

Quote page → Products where useful

The logo should always link to Home.

---

# 26. Anchor Text

Prefer descriptive anchor text.

Good:

**Explore the Clean Process Chamber**

**View Clean-Air Workstations**

**Request a Quote**

Avoid generic anchor text such as:

**Click here**

**Learn more**

when a more descriptive label makes sense.

---

# 27. Navigation Links

Primary navigation links are important internal links.

Use exactly:

* Home
* Products
* Contact
* Request a Quote

Do not change link names simply to insert more keywords.

---

# 28. Canonical Domain

Use the production custom domain configured through the repository `CNAME` file.

Do not use the GitHub Pages subdomain as the canonical domain when a custom domain is active.

Each public page should have a self-referencing canonical URL where appropriate.

---

# 29. Canonical URL Rules

Preferred pattern:

```text
https://[production-domain]/
https://[production-domain]/products
https://[production-domain]/contact
https://[production-domain]/request-a-quote
```

Use the actual production URL structure implemented by the site.

Do not create canonicals pointing to nonexistent routes.

---

# 30. URL Structure

Keep URLs:

* Short
* Lowercase
* Human readable
* Stable

Preferred:

```text
/products
/contact
/request-a-quote
```

Avoid:

```text
/page2
/product-new-final
/products.html?id=1
```

If the static hosting implementation requires `.html`, preserve a consistent strategy.

Do not break deployed URLs unnecessarily.

---

# 31. Redirects

If legacy URLs are removed and redirect functionality is available, redirect valuable relevant URLs to the closest current page.

Do not redirect unrelated old fixture/CNC pages to the homepage merely to preserve traffic.

If no meaningful replacement exists, a clean 404 may be better.

---

# 32. Legacy Content

Previous site iterations may include:

* Fixture design pages
* CNC setup articles
* Workholding content
* Engineering consulting pages
* Old case studies

These topics do not match the new Eden positioning.

Do not keep them indexed simply because they already exist.

Remove or deindex obsolete content when it no longer reflects the business.

---

# 33. Sitemap

Maintain a sitemap containing only active, indexable public pages.

Initial sitemap:

```text
/
 /products
 /contact
 /request-a-quote
```

Do not include:

* `/docs`
* Internal planning files
* Temporary pages
* Old removed pages
* Development files

---

# 34. Robots.txt

The production site should generally be indexable.

Do not accidentally use:

```text
Disallow: /
```

on the production site.

Block internal/non-public paths only when needed.

---

# 35. Docs Folder

The `/docs` folder contains internal project documentation.

It is not intended to be customer-facing SEO content.

Do not link to internal planning Markdown files from the public website.

Where practical, prevent internal documentation from becoming part of the public customer experience.

---

# 36. Open Graph Metadata

Each page should have:

* `og:title`
* `og:description`
* `og:url`
* `og:type`
* `og:image`

Use a confirmed Eden visual asset.

Do not use a generic unrelated stock image.

---

# 37. Social Preview Image

Preferred social preview:

* Eden logo
* Clean Process Chamber image/render
* Clean background
* Minimal text

Avoid placing long marketing copy inside the image.

---

# 38. Image File Names

Use descriptive image names.

Good:

```text
eden-clean-process-chamber.webp
clean-process-chamber-airflow.svg
stainless-cleanroom-workstation.webp
```

Avoid:

```text
IMG_4382.jpg
finalfinal2.png
image1.png
```

---

# 39. Image Alt Text

Use descriptive alt text.

Examples:

**Eden Clean Process Chamber with overhead HEPA filtration module**

**Diagram showing downward filtered airflow through the Clean Process Chamber**

**Stainless Eden cleanroom workstation**

Do not keyword-stuff alt text.

---

# 40. Product Imagery and Search

Important product images should be placed near relevant HTML text describing the product.

Do not rely solely on text embedded inside diagrams or renders.

Search engines and users both need accessible HTML content.

---

# 41. Technical Diagrams

For important diagrams, provide surrounding HTML copy that explains:

* What the diagram shows
* What components are involved
* How airflow moves

Do not rely on the graphic alone.

---

# 42. Structured Data

Structured data may be used if accurate.

Potential future schema types:

* Organization
* Product
* BreadcrumbList

Do not add Product schema with invented values.

---

# 43. Organization Schema

Only include confirmed information such as:

* Company name
* Canonical URL
* Logo
* Confirmed contact information

Do not invent:

* Address
* Telephone
* Social profiles

---

# 44. Product Schema

Do not add product fields unless confirmed.

Do not invent:

* SKU
* MPN
* Price
* Availability
* Review
* Rating
* Brand values beyond confirmed information

If product information is too incomplete, omit Product schema until later.

---

# 45. Review Schema

Do not create:

* Review schema
* AggregateRating
* Testimonial markup

unless real reviews exist and meet search-engine guidelines.

---

# 46. Local SEO

Do not pursue local SEO aggressively unless Eden wants local business visibility.

If a physical business location is later confirmed and intended to be public, local SEO may include:

* Consistent business name
* Address
* Phone
* Google Business Profile
* Organization schema

Do not invent location details.

---

# 47. Keyword Stuffing

Never write copy like:

> Eden clean-air workstations are clean-air workstations designed for clean-air workstation customers looking for HEPA clean-air workstations.

Write naturally.

Search terminology should appear because it accurately describes the product.

---

# 48. Search Term Accuracy

Do not chase a keyword if it inaccurately describes the product.

For example:

If users commonly search for "biosafety cabinet," that does not justify describing Eden's current product as a biosafety cabinet.

If users search for "laminar flow hood," do not automatically use that term unless product performance supports it.

SEO must follow the product.

---

# 49. Clean Bench Terminology

"Clean bench" may be useful in educational or comparative language because customers may search for it.

However, do not call the Eden Clean Process Chamber a clean bench unless that category accurately matches the final product.

Safe contextual use:

> Customers evaluating clean benches, clean-air workstations, or localized clean zones may consider the Eden Clean Process Chamber depending on their application.

Do not use this exact sentence unless it fits the final content naturally.

---

# 50. Laminar Flow Keywords

Do not target "laminar flow" aggressively before validation.

If future airflow testing supports appropriate use of the term, SEO strategy may be updated.

Until then, prefer:

* Vertical airflow
* Downward filtered airflow
* HEPA-filtered workstation

---

# 51. ISO Keywords

Do not target ISO class keywords as product claims before validation.

Avoid titles such as:

**ISO Class 5 Clean Workstation**

unless testing supports that specific classification.

---

# 52. Application Keywords

Applications may be discussed naturally within Home and Products.

Potential themes:

* Clean air for assembly
* Clean workstation for inspection
* Clean environment for packaging
* HEPA workstation for electronics assembly
* Localized clean air for precision manufacturing

Do not create separate landing pages for every phrase yet.

---

# 53. Content Expansion Rule

Only create new SEO pages when all of the following are true:

1. There is meaningful search intent.
2. Eden has real expertise/content for the topic.
3. The page would help a buyer.
4. The page would contain substantial unique content.
5. The page fits the current business strategy.

Do not create thin pages just to target keywords.

---

Potential future content, once the core site is established:

* Clean bench vs cleanroom

* Understanding HEPA filtration for manufacturing workstations
* Vertical vs horizontal airflow workstations
* How to choose a clean-air workstation

These are future opportunities, not required launch pages.

---

# 55. Search Console

Once the site is live on the production domain, connect Google Search Console if not already configured.

Use it to monitor:

* Indexed pages
* Search queries
* Clicks
* Impressions
* Crawl errors
* Sitemap status

Do not change content based solely on individual low-volume query fluctuations.

---

# 56. Analytics

Analytics is optional and should only be added intentionally.

If analytics is added, useful SEO/conversion metrics include:

* Organic sessions
* Product page visits
* Request a Quote clicks
* Quote form submissions
* Contact form submissions
* Search landing pages

Do not install analytics merely because SEO documentation mentions it.

---

# 57. Core Web Vitals

SEO implementation should support good performance.

Prioritize:

* Fast initial rendering
* Stable layout
* Optimized hero imagery
* Minimal blocking scripts
* Efficient fonts
* Limited JavaScript

Avoid sacrificing user experience for decorative effects.

---

# 58. Largest Contentful Paint

The likely LCP element may be the hero product image or headline.

Optimize accordingly.

Do not ship an unnecessarily large hero image.

---

# 59. Cumulative Layout Shift

Reserve dimensions for:

* Images
* Diagrams
* Form elements

Avoid content jumping as resources load.

---

# 60. JavaScript and SEO

Core product content must exist in readable HTML.

Do not require JavaScript to generate essential:

* Page headings
* Product descriptions
* Navigation
* Specifications
* Contact information

when avoidable.

---

# 61. Duplicate Content

Avoid duplicating large blocks of identical product copy across multiple pages.

Some repeated short messaging is acceptable.

For example:

**Control the process environment, not the entire room.**

may appear in multiple strategic locations.

Do not repeat entire product descriptions verbatim everywhere.

---

# 62. Product Name Consistency

Use the product name consistently:

**Eden Clean Process Chamber**

Avoid unnecessary variations such as:

* Eden CPC
* Clean Chamber System
* Process Clean Box
* Eden Air Chamber

unless a future naming decision changes the official name.

Consistent naming helps both users and search engines.

---

# 63. Brand Name Consistency

Use:

**Eden Industrial Systems**

Do not inconsistently alternate between:

* Eden Cleanrooms
* Eden Systems
* ECS Cleanroom
* Eden Clean Systems

unless context explicitly calls for a shortened brand reference.

---

# 64. Meta Keywords

Do not use the obsolete `meta keywords` tag.

Modern SEO does not require it.

---

# 65. Title Length

Keep titles concise and descriptive.

Do not obsess over exact character counts, but avoid titles so long that important information is consistently truncated.

Place the most useful concept early.

---

# 66. Meta Description Length

Write useful descriptions for humans.

Do not stuff keyword variants.

Search engines may rewrite descriptions, so the goal is clarity rather than exact display control.

---

# 67. Home Page Search Message

A search visitor landing on the homepage should quickly understand:

> Eden manufactures equipment for localized process environments for critical processes.

That concept should be visible without scrolling excessively.

---

# 68. Products Page Search Message

A search visitor landing directly on Products should quickly understand:

> Eden offers a Clean Process Chamber and stainless cleanroom workstations.

The product should be visible near the top.

---

# 69. Conversion From Organic Traffic

Organic traffic should have a clear next action.

Important CTAs:

* Request a Quote
* View Products
* Contact Eden

Request a Quote should remain the primary commercial action.

---

# 70. Footer SEO

The footer should include useful navigation, but should not become a keyword list.

Do not add dozens of SEO links.

Use the approved four-page navigation.

---

# 71. Hidden SEO Text

Do not use:

* Invisible text
* Off-screen keyword blocks
* Tiny keyword text
* Hidden duplicate headings

All SEO content should provide value to visible users.

---

# 72. Link Quality

Do not add irrelevant outbound links merely for SEO.

When external links are useful, prefer authoritative technical sources.

---

# 73. Backlink Strategy

Backlinks may eventually come from:

* Industry directories
* Manufacturing partners
* Suppliers
* Relevant trade publications
* Real customer references
* Engineering resources

Do not purchase spammy backlink packages.

---

# 74. Competitor Names

Do not use competitor brand names in copy merely to attract their search traffic.

Comparative content should only be created when it provides legitimate value and can be written accurately.

---

# 75. Search Performance Review

After launch, SEO decisions should be based on actual data.

Review:

* Which queries generate impressions
* Which pages receive clicks
* Which commercial terms are emerging
* Which applications users search for
* Where visitors convert

Future content strategy should respond to evidence.

---

# 76. No SEO-Driven Technical Claims

Never add phrases such as:

* ISO Class 5
* Sterile
* Laminar flow
* Medical-grade
* Pharmaceutical-grade

solely because keyword research shows demand.

`CLAIMS.md` always overrides SEO opportunity.

---

# 77. SEO Content Priority

At launch, prioritize:

1. Strong homepage
2. Strong Products page
3. Accurate titles and metadata
4. Proper internal links
5. Clear heading structure
6. Good performance
7. Image optimization
8. Sitemap/canonical setup
9. Search Console
10. Future content based on real search data

Do not start by creating dozens of articles.

---

# 78. Launch SEO Checklist

Before launch, verify:

* Homepage has unique title
* Products has unique title
* Contact has unique title
* Request a Quote has unique title
* Every page has a meta description
* One H1 per page
* Heading hierarchy is logical
* Canonical URLs are correct
* Production domain is correct
* Sitemap contains active public pages
* Robots configuration does not block production
* Images have useful alt text
* Hero image is optimized
* Internal navigation works
* No links point to deleted legacy content
* Open Graph metadata is configured
* Favicon works
* No unsupported technical claims appear
* No placeholder metadata remains

# 80. Final SEO Principle

The SEO strategy should make Eden easier to discover without changing what Eden actually is.

The order of priority is:

**Product truth → customer clarity → search optimization**

Not:

**Search volume → marketing claim → product reality**

The website should rank because it clearly explains a real and useful product category.

The central search and brand proposition remains:

> # Control the process environment, not the entire room.
