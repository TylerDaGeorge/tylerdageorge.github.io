# CEC — HEPA-Filtered Clean Staging Chamber

This former product-definition filename is retained for repository continuity. The current approved CEC definition is maintained in [`CEC.md`](CEC.md).

The CEC is a standalone-capable benchtop chamber for point-of-use clean WIP staging and may also be integrated with an EIS Clean Environment Table as the CEW. It remains in prototype and pilot development. Do not infer performance, certification, cleanliness classification, dimensions, loading, electrical requirements, or filter-service details beyond the current approved definition.
