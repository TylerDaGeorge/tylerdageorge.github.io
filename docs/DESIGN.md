# Design Direction

Present precision mechanical engineering with restrained blue-green, green, steel-gray, white, and neutral colors. Prioritize approved genuine fixture imagery when supported by the delivery format, then capability clarity, process, technical credibility, and project review. Use strong hierarchy, whitespace, restrained borders, responsive grids, visible focus, and reduced-motion support. Use a text-led layout when approved project imagery cannot be included. Avoid stock imagery, fictional renders, decorative dashboards, and exaggerated corporate styling.
